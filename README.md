# ✨ SiteForge — Визуальный конструктор сайтов v6.0

**SiteForge** — это конструктор сайтов, который работает прямо в браузере. Тебе не нужно знать HTML, CSS или какой-либо язык программирования. Открываешь файл, настраиваешь всё через удобную панель, жмёшь «Скачать» — и готовый сайт у тебя!

---

## 🚀 Что внутри

- **Полноценный одностраничный сайт** (лендинг) с шапкой, Hero-блоком, карточками, секциями и подвалом
- **Удобная панель управления** слева — все настройки разбиты по 10 разделам
- **Живой предпросмотр** — изменения отображаются мгновенно (с задержкой 300мс для плавности)
- **Режимы просмотра**: 💻 Десктоп / 📱 Планшет / 📱 Телефон
- **Автосохранение** всех настроек в браузере — ничего не пропадёт
- **Кастомный курсор** с эффектами наведения для приятной работы

## 🃏 Динамический контент

### Карточки услуг
- **Любое количество карточек** — добавляйте, удаляйте, меняйте местами
- **Drag-and-drop** для изменения порядка
- Название, описание, иконка (эмодзи) для каждой
- Настройка фона, количества в ряду, тени

### Пункты меню
- **Динамическое добавление** пунктов с настраиваемыми ID якорей
- Drag-and-drop для сортировки
- Каждый пункт автоматически создаёт секцию

### Дополнительные секции
- **Создавайте сколько угодно** секций: О нас, Команда, Отзывы, Галерея, Цены...
- Заголовок, текст, уникальный ID для якоря
- Drag-and-drop для изменения порядка

### Соцсети в подвале
- **Неограниченное количество** соцсетей
- Drag-and-drop для сортировки
- **3 стиля отображения**: кнопки, текст с иконками, только иконки
- **3 размера**: маленький, обычный, крупный

## 🎨 Детальные настройки

### Фон и общие стили
- Тип фона: сплошной цвет, градиент или изображение
- Два цвета + направление градиента
- Цвет текста, акцентный цвет

### Шапка и меню
- **Текстовый логотип** или **загрузка изображения** (drag-and-drop файлов)
- Цвет фона, текста, **прозрачность** (0-100%)
- **Эффекты при наведении**: подчёркивание, свечение, масштаб
- Закрепление при скролле

### Главный блок (Hero)
- Заголовок, подзаголовок
- **Загрузка фонового изображения** или URL
- Высота блока, **выравнивание** (left/center/right)
- **Стиль заголовка**: обычный, градиент, заглавные буквы

### Кнопки
- **Главная кнопка** — текст, ссылка, цвета, скругление, размер шрифта
- **Кнопки в карточках** — вкл/выкл, текст, цвета
- **2 дополнительные кнопки** в любом месте страницы

### Типографика
- Шрифты для заголовков и текста (7 шрифтов на выбор)
- Скругление элементов, масштаб заголовков
- **Межстрочный интервал**

### Анимации
- **4 типа анимаций** для карточек: появление, скольжение, масштаб, пружина
- **4 типа анимаций** для секций
- **4 эффекта кнопок** при наведении: подъём, свечение, масштаб, тряска
- **3 скорости** анимаций

## 📥 Как пользоваться

1. **Открой файл `constructor.html`** в любом современном браузере
2. **Выбери пресет** (раздел «🎭 Пресеты») или настрой вручную
3. **Слева выбери раздел** — Фон, Шапка, Hero, Карточки и т.д.
4. **Добавляй контент динамически** — карточки, секции, соцсети
5. **Изменения применяются автоматически** — кнопка «Применить» не обязательна
6. **Жми «💾 Скачать HTML»** — получи готовый сайт

## ⚡ Продвинутые возможности

### Горячие клавиши
- `Ctrl + Z` — отменить изменение
- `Ctrl + Y` / `Ctrl + Shift + Z` — повторить
- `Ctrl + S` — скачать сайт

### История изменений
- **До 50 шагов** истории
- Полный Undo/Redo всех действий

### Экспорт/Импорт проекта
- **Сохраняй проекты** в JSON-файл
- **Делись проектами** с друзьями
- **Загружай** ранее сохранённые проекты

### Загрузка изображений
- **Drag-and-drop** файлов в специальные зоны
- Поддержка логотипа и фона Hero
- Автоматическая конвертация в Base64

## 🎯 Кастомный курсор

Особая фишка v6.0 — **двойной кастомный курсор**:
- Маленькая точка точно следует за мышью
- Кольцо плавно догоняет с эффектом «инерции»
- **Превращается** при наведении на кнопки, ссылки, текстовые поля
- **Автоматически отключается** на мобильных устройствах
