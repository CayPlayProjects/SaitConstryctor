# ✦ SiteForge v7 — визуальный блочный конструктор сайтов

SiteForge — браузерный конструктор лендингов без сборщика, сервера и обязательной регистрации. Проект запускается как обычный статический сайт: откройте `index.html` или разместите репозиторий на GitHub Pages.

## Что изменилось в v7

Вместо фиксированных разделов SiteForge теперь использует **блочную модель**. Страница собирается из независимых блоков, которые можно добавлять, редактировать, дублировать, скрывать, удалять и переставлять.

### Библиотека блоков

- Hero / первый экран
- Текстовый блок
- Преимущества
- Карточки услуг / проектов
- Статистика
- Галерея
- Отзывы
- Тарифы
- FAQ
- CTA / призыв к действию
- Контакты
- Логотипы партнёров
- Разделитель
- Отступ

### Новый интерфейс конструктора

- слева — **библиотека блоков**, структура страницы и шаблоны;
- по центру — живой предпросмотр;
- справа — понятный инспектор выбранного блока;
- отдельные режимы **Desktop / Tablet / Mobile**;
- масштаб предпросмотра;
- выбор блока прямо кликом по предпросмотру;
- drag-and-drop сортировка структуры;
- отдельный полноэкранный предпросмотр.

### Готовые шаблоны

Встроены стартовые структуры:

- Бизнес
- Портфолио
- Продукт / SaaS
- Событие
- Чистый проект

Шаблон создаёт структуру, после чего любой блок можно полностью изменить.

## Управление дизайном

Глобально настраиваются:

- фон, основной цвет текста, вторичный текст;
- акцентный цвет;
- поверхности карточек и границы;
- основной шрифт и шрифт заголовков;
- насыщенность заголовков;
- ширина контейнера;
- скругления;
- интенсивность теней;
- собственный CSS.

Для каждого блока отдельно доступны фон, цвет текста, вертикальные отступы и максимальная ширина контента. У Hero есть отдельные настройки градиента, изображения, затемнения, высоты и выравнивания.

## Шапка, меню и навигация

SiteForge автоматически собирает меню из блоков, у которых включена опция **«Показывать в меню»**. Для каждого блока можно изменить:

- имя внутри конструктора;
- якорь (`#features`, `#contact` и т.д.);
- название пункта меню;
- видимость в меню;
- видимость самого блока.

Шапку можно закрепить сверху, настроить логотип и CTA-кнопку.

## Проекты и сохранение

- автоматическое сохранение в `localStorage`;
- несколько проектов на одном устройстве;
- окно **«Мои проекты»**;
- импорт/экспорт проекта в JSON;
- Undo / Redo до 80 состояний;
- отдельный экспорт готового сайта в один HTML-файл.

### Горячие клавиши

- `Ctrl/Cmd + Z` — отменить;
- `Ctrl/Cmd + Y` или `Ctrl/Cmd + Shift + Z` — повторить;
- `Ctrl/Cmd + S` — сохранить проект локально;
- `Ctrl/Cmd + E` — скачать готовый HTML;
- `Delete` — удалить выбранный блок;
- `Esc` — закрыть модальные окна и мобильные панели.

## SEO

В разделе «Настройки сайта → Ещё» доступны:

- title страницы;
- meta description;
- favicon URL;
- язык документа;
- плавная прокрутка;
- пользовательский CSS.

## Экспортированный сайт

Кнопка **«Скачать HTML»** создаёт самостоятельный HTML-файл, в котором уже находятся:

- адаптивная верстка;
- стили выбранной темы;
- мобильное меню;
- FAQ;
- вся структура и контент проекта;
- пользовательский CSS.

Сам интерфейс конструктора в экспортированный файл не попадает.

## Запуск

Можно просто открыть `index.html`. Для разработки удобнее запустить любой статический сервер, например:

```bash
python -m http.server 8080
```

и перейти на `http://localhost:8080`.
