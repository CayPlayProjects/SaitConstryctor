<a id="start"></a>
## 🚀 Быстрый старт

**Вариант 1 — просто открыть:**

```text
Двойной клик по index.html → готово. Работает прямо из папки.
```

**Вариант 2 — локальный сервер (удобнее для разработки):**

```bash
python -m http.server 8080
```

и перейти на `http://localhost:8080`.

**Вариант 3 — GitHub Pages:** загрузите репозиторий и включите Pages — конструктор будет доступен по ссылке.

> 📦 **Почему один файл — это удобно:** его можно носить на флешке, отправить в мессенджере, открыть на любом компьютере и захостить где угодно. Ничего не нужно устанавливать.

<a id="interface"></a>
## 🖥 Интерфейс

```text
┌──────────────────────────────────────────────────────────────┐
│ ✦ SiteForge   [Название проекта]    🎨  ↶ ↷  ⌘K  👁  ⬇ HTML │
├─────────────┬────────────────────────────────┬───────────────┤
│  Блоки      │                                │  Инспектор    │
│  Структура  │      Живой предпросмотр        │  · Контент    │
│  Шаблоны    │   Desktop / Tablet / Mobile    │  · Стиль      │
│             │          масштаб 50–125 %      │  · Ещё        │
├─────────────┴────────────────────────────────┴───────────────┤
│ ● SiteForge v9 · Desktop · 8 блоков   [Блок] [Проверка] [?]  │
└──────────────────────────────────────────────────────────────┘
```

- **Слева** — библиотека, структура с drag-and-drop, шаблоны и проекты.
- **В центре** — холст: клик по секции выбирает блок, наведение подсвечивает.
- **Справа** — инспектор: контент, стиль и настройки выбранного блока или всего сайта.
- **Снизу** — статус-панель с быстрыми действиями.

**Режимы работы** (запоминаются между сессиями):

| Режим | Что делает |
|---|---|
| 🎯 Фокус | Скрывает обе боковые панели |
| 🖼 Презентационный | Убирает весь интерфейс вокруг холста |
| # Сетка холста | Направляющая сетка для аккуратной композиции |
| ↔ Компактные панели | Уже боковые панели — больше места сайту |

<a id="audit"></a>
## ✅ Проверка сайта

Локальный аудит перед публикацией — `Ctrl + Q` или кнопка «Проверка». Показывает **балл 0–100** и конкретные замечания:

- [x] длина `title` (15–65 символов);
- [x] наличие и размер `meta description` (70–170);
- [x] ровно один `H1`;
- [x] `alt` у всех изображений;
- [x] отсутствие пустых ссылок `href="#"`;
- [x] количество секций.

> Это быстрый встроенный помощник, а не замена внешним SEO-сервисам.

## 🎛 Управление дизайном

| Глобально (весь сайт) | Для каждого блока |
|---|---|
| Фон, текст, вторичный текст | Фон и цвет текста |
| Акцент, поверхности, границы | Вертикальные отступы |

| Пользовательский CSS | |

**Шапка и навигация:** меню собирается автоматически из блоков с опцией «Показывать в меню». Для каждого блока настраиваются имя, якорь, название пункта и видимость. Шапку можно закрепить сверху, задать логотип (текст или изображение) и CTA-кнопку.

## 📤 Экспортированный сайт

Кнопка **«Скачать HTML»** создаёт самостоятельный файл, в котором уже есть:

- ✅ мобильное меню и FAQ;
- ✅ вся структура и контент проекта;
- ✅ пользовательский CSS.

Интерфейс конструктора и инструменты v9 в экспортированный сайт **не попадают** — только чистый сайт.
