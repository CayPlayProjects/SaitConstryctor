# ✦ SiteForge v8 — визуальный конструктор сайтов

SiteForge — браузерный блочный конструктор лендингов без сервера, сборщика и обязательной регистрации. Проект работает как обычный статический сайт: можно открыть `index.html` локально или разместить репозиторий на GitHub Pages.

## Что нового в v8

Версия 8 сохраняет блочный редактор v7, но заметно улучшает ежедневную работу с ним.

### Командный центр

Нажмите **Ctrl/Cmd + K** или кнопку **«Быстро»** в верхней панели. Через один поиск доступны:

- библиотека блоков;
- структура страницы;
- готовые шаблоны;
- настройки сайта;
- мои проекты;
- импорт и экспорт JSON;
- Desktop / Tablet / Mobile;
- полный предпросмотр;
- режим фокуса;
- презентационный режим;
- сетка холста;
- компактные панели;
- скачивание и копирование HTML;
- резервная копия всех проектов;
- встроенная проверка сайта;
- справка по горячим клавишам.

### Проверка сайта

В SiteForge v8 появился локальный аудит текущего результата. Он проверяет:

- длину `title`;
- наличие и размер `meta description`;
- количество `H1`;
- `alt` у изображений;
- пустые ссылки `href="#"`;
- количество секций/блоков.

После проверки показывается общий балл и конкретные замечания. Это быстрый встроенный помощник перед публикацией, а не замена внешним SEO-сервисам.

### Резервные копии

Команда **«Резервная копия всего»** собирает данные SiteForge из `localStorage` и сохраняет их одним JSON-файлом. Это удобно перед очисткой браузера, крупными изменениями или переносом работы.

### Режимы работы

- **Фокус** — скрывает обе боковые панели и оставляет максимум места холсту.
- **Презентационный режим** — убирает лишний интерфейс вокруг предпросмотра.
- **Сетка холста** — визуальная направляющая для аккуратной композиции.
- **Компактные панели** — уменьшает ширину боковых панелей.
- Выбранные режимы запоминаются между перезапусками.

### Быстрая нижняя панель

Внизу редактора отображаются:

- активный режим устройства;
- количество блоков;
- состояние SiteForge v8;
- быстрый переход в режим фокуса;
- запуск проверки сайта;
- справка.

Также рядом с холстом доступны быстрые кнопки **«+ Блок»** и **«Проверка»**.

## Библиотека блоков

Базовый редактор v7 по-прежнему содержит:

- Hero / первый экран;
- текстовый блок;
- преимущества;
- карточки услуг / проектов;
- статистику;
- галерею;
- отзывы;
- тарифы;
- FAQ;
- CTA / призыв к действию;
- контакты;
- логотипы партнёров;
- разделитель;
- отступ.

Каждый блок можно добавлять, редактировать, дублировать, скрывать, удалять и переставлять.

## Интерфейс конструктора

- слева — библиотека блоков, структура и шаблоны;
- по центру — живой предпросмотр;
- справа — инспектор выбранного блока;
- сверху — Undo / Redo, предпросмотр, экспорт и командный центр;
- Desktop / Tablet / Mobile;
- масштаб предпросмотра;
- выбор блока кликом по предпросмотру;
- drag-and-drop сортировка структуры;
- отдельный полноэкранный предпросмотр.

## Готовые шаблоны

Встроены стартовые структуры:

- Бизнес;
- Портфолио;
- Продукт / SaaS;
- Событие;
- Чистый проект.

Шаблон создаёт основу, после чего любой блок можно изменить.

## Управление дизайном

Глобально настраиваются:

- фон и основной цвет текста;
- вторичный текст;
- акцент;
- поверхности карточек и границы;
- основной шрифт и шрифт заголовков;
- насыщенность заголовков;
- ширина контейнера;
- скругления;
- тени;
- пользовательский CSS.

Для каждого блока отдельно доступны фон, цвет текста, вертикальные отступы и максимальная ширина контента.

## Шапка, меню и навигация

SiteForge автоматически собирает меню из блоков, у которых включена опция **«Показывать в меню»**. Для каждого блока можно изменить:

- имя внутри конструктора;
- якорь;
- название пункта меню;
- видимость в меню;
- видимость самого блока.

Шапку можно закрепить сверху, настроить логотип и CTA-кнопку.

## Проекты и сохранение

- автоматическое сохранение в `localStorage`;
- несколько проектов на одном устройстве;
- окно «Мои проекты»;
- импорт/экспорт проекта в JSON;
- резервная копия всех проектов v8;
- Undo / Redo до 80 состояний;
- экспорт готового сайта в один HTML-файл;
- копирование сгенерированного HTML прямо из командного центра.

## Горячие клавиши

Базовые:

- `Ctrl/Cmd + Z` — отменить;
- `Ctrl/Cmd + Y` или `Ctrl/Cmd + Shift + Z` — повторить;
- `Ctrl/Cmd + S` — сохранить проект локально;
- `Ctrl/Cmd + E` — скачать готовый HTML;
- `Delete` — удалить выбранный блок;
- `Esc` — закрыть окна.

Новые в v8:

- `Ctrl/Cmd + K` — командный центр;
- `Ctrl/Cmd + A` — библиотека блоков;
- `Ctrl/Cmd + P` — полный предпросмотр;
- `Ctrl/Cmd + Q` — проверка сайта;
- `Ctrl/Cmd + F` — режим фокуса.

## SEO

В настройках сайта доступны:

- title страницы;
- meta description;
- favicon URL;
- язык документа;
- плавная прокрутка;
- пользовательский CSS.

В v8 эти параметры дополнительно проверяются встроенным аудитом.

## Экспортированный сайт

Кнопка **«Скачать HTML»** создаёт самостоятельный HTML-файл, в котором уже находятся:

- адаптивная верстка;
- стили выбранной темы;
- мобильное меню;
- FAQ;
- структура и контент проекта;
- пользовательский CSS.

Интерфейс конструктора и инструменты v8 в экспортированный сайт не попадают.

## Запуск

Можно просто открыть `index.html`. Для разработки удобнее запустить статический сервер:

```bash
python -m http.server 8080
```

и перейти на `http://localhost:8080`.
